# tensei-roguelite-legal

異世界転生（iOS）の法務ページ。GitHub Pages で公開する。

- `index.html` — トップ（各ページへの導線・お問い合わせ）
- `privacy-policy.html` — プライバシーポリシー
- `terms-of-service.html` — 利用規約
- `tokushoho.html` — 特定商取引法に基づく表記

日本語のみ（アプリの対応ロケールが ja のため）。

アプリ名は仮決め。変えるときは各ページの「異世界転生」を置き換える。
内容は、計測・広告・課金の実装(`tensei-roguelite/lib/services/`)を変えたら合わせて直す。
